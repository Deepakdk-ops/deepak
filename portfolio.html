About

Production-minded backend engineering

I'm a backend engineer focused on scalable REST APIs, database performance, and production reliability. Most of my career has been at Tecnospice, building a multi-module healthcare platform — appointments, patient records, prescriptions, and billing — on Django REST Framework and MySQL.

Beyond building features, I own what happens when things break: triaging live issues through log analysis, coordinating directly with clients, and shipping fixes safely with blue-green deployment. I work across the async and real-time stack — Celery and Redis for background jobs, WebSockets for emergency alerts — and deploy on AWS. I also run backend code reviews and mentor junior developers.
